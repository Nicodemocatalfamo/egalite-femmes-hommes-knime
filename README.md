
# Analyse de l’égalité femmes-hommes — KNIME

Projet réalisé dans le cadre de ma **certification Data Analyst**.

## Présentation

Ce projet consiste à préparer et analyser des données relatives à l’égalité professionnelle entre les femmes et les hommes.

L’objectif est de construire un processus de traitement fiable permettant de produire des indicateurs exploitables tout en respectant les règles de qualité des données et de confidentialité.

## Démarche

Le projet comprend notamment :

- la collecte et l’intégration des données ;
- le contrôle de leur conformité ;
- le nettoyage et la préparation des données ;
- l’automatisation des traitements avec KNIME ;
- la construction d’indicateurs relatifs à l’égalité femmes-hommes ;
- la vérification de la qualité des données produites ;
- la restitution des résultats.

## Compétences mises en œuvre

- Préparation et nettoyage de données
- Construction d’un workflow KNIME
- Automatisation de traitements
- Contrôle qualité des données
- Construction d’indicateurs
- Analyse RH
- Respect des règles de confidentialité et du RGPD
- Restitution des résultats

## Contenu du dépôt

Le dépôt comprend :

- le workflow KNIME utilisé pour préparer et analyser les données ;
- la base de données finale issue des traitements ;
- une présentation synthétisant l’analyse réalisée.

## Ce que ce projet démontre

Ce projet montre ma capacité à construire un processus de traitement reproductible, contrôler la qualité des données et produire des indicateurs utilisables dans un contexte RH.

Il illustre également ma capacité à utiliser un outil de préparation de données visuel pour automatiser une chaîne de traitement.

**Outils :** KNIME · Data preparation · Analyse RH · Qualité des données · RGPD
